PERSONAL PORTFOLIO - PHOTO SETUP

Your Home page is already configured to load:
images/profile-placeholder.svg

To add your own professional photo:
1. Put your photo inside the images folder.
2. Rename it to profile.jpg.
3. Open index.html.
4. Change:
   src="images/profile-placeholder.svg"
   to:
   src="images/profile.jpg"

You can also use PNG by changing the filename to profile.png.

The rest of the portfolio is ready for GitHub Pages, Netlify, or Vercel.
